# Terminal

A dark terminal window that shows work being done and checked: the brand's "agents at work" motif.

A `radius-card` panel on `brand-900` with a `brand-800` title bar (`terminal-caption`) and a body in `terminal`. The prompt `$` and row keys are `accent-500`; checks ("✓ ready", "✓ proven") are `accent-400`; the closing cursor is the logo's mint bar. On the site the command types itself and each row appears in turn; under reduced motion it shows complete.

The consumer provides the command and the rows. In Relay use it for agent runs and proof checks. Keep it to real output, never decorative fake logs.
