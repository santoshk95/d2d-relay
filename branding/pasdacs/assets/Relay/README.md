# Relay

Proposed lockups for RELAY by PASDACS, built from the PASDACS mark. They are new and not yet on pasdacs.com.

- `relay-lockup.svg`: for light grounds. Ink tile and RELAY in `#111111`, BY PASDACS in `#525252`.
- `relay-lockup-dark.svg`: for dark grounds. White tile, RELAY in white, BY PASDACS in `#A3A3A3`.
- `powered-by.svg`: "Powered by PASDACS Relay" badge for partner-branded workspaces, emails and PDFs. Text in `#525252` and `#111111`; use on light grounds.

Text is live Manrope 800 / Inter; outline it before print.
