# Logos

The PASDACS "fast forward" mark and lockups, copied unchanged from pasdacs.com (`public/brand/`, `src/app/icon.svg`).

- `logo.svg`: mark + PASDACS wordmark, for light grounds. Ink `#111111`, chevrons white, cursor `#00C48C`.
- `logo-dark.svg`: for dark grounds. White tile, ink chevrons, white wordmark.
- `logo-mark.svg`: the mark alone, 48×48.
- `favicon-mark.svg`: the mark with heavier strokes, for 16–48px (browser tabs, app icons).
- `logo-mark.png`: 512×512 mark, for structured data and app stores.
- `logo-email.png`: transparent lockup for email signatures.
- `og-default.png`: 1200×630 social sharing image.

The SVG wordmarks are live text in Manrope 800. Where Manrope is not installed, outline the text before sending the file to print or a third party.
